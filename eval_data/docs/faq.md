# FAQ

## Is my source code sent to the model?
No. repobrief sends the README, the file tree and recent commit messages. File contents
are never sent.

## Which models can I use?
Any model with an OpenAI-compatible API, or a local model through Ollama.

## Can I use it offline?
Yes, with a local model through Ollama. Summarizing still needs access to GitHub.

## Does it support GitLab or Bitbucket?
Not yet. Only GitHub repositories are supported.
